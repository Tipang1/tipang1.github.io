Vaultiq

Vaultiq est un gestionnaire de mots de passe hors ligne pour Windows. Toutes les données sont stockées localement dans un coffre chiffré, sans cloud, sans compte, et sans connexion internet.

Objectifs

  • Proposer un gestionnaire de mots de passe simple et rapide à utiliser
  • Garantir un stockage local chiffré et sécurisé avec un mot de passe maître
  • Ne dépendre d’aucun service en ligne ni d’aucun compte
  • Rester léger et compréhensible pour un usage quotidien

Démarrage rapide

Vaultiq est un projet open-source développé dans le cadre du défi « Un mois, une fonctionnalité » (2026).
Pour un usage critique ou professionnel, privilégiez des solutions éprouvées comme Bitwarden ou KeePass.

  2. Lancez l’application (Vaultiq ou Vaultiq.exe)
  3. Créez un coffre avec un mot de passe maître

Vaultiq

Vaultiq is an offline password manager for Windows. All data is stored locally in an encrypted vault, with no cloud, no account, and no internet connection required.

Goals

  • Provide a simple and fast password manager
  • Ensure secure local encrypted storage using a master password
  • Remain fully offline with no online services or accounts
  • Stay lightweight and easy to use on a daily basis

Quick start

Vaultiq is an open-source project developed as part of the “1 month, 1 app” challenge (January 2026).
For critical or professional use, consider established solutions such as Bitwarden or KeePass.
  1. Download Vaultiq.exe from the ˜Releases
  2. Launch the application (Vaultiq or Vaultiq.exe)
  3. Create a vault using a master password
